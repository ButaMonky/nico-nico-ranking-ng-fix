# 回帰試験計画（全項目未実施）

これは計画でありPASS一覧ではありません。v14.1の実測値はまだ取得していません。原本を基準に、同一の入力・設定・応答順・観測時点を固定して期待値を取得します。NG内部関数をコピーして独立実装の結果を期待値にしてはいけません。
