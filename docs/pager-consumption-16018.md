# 160.18 処理済みページの斜線修正

一度直接開いたページを「開始ページ」として記憶し、その後別ページから全動画を取得・処理しても斜線の対象から永久に除いていた。現在のページだけを選択中の番号として残し、過去の開始ページも改めて全動画の表示またはNG判定が完了すれば処理済みにする。

取得のみ・候補の未表示・判定未完了・失敗が残るページを飛ばす条件は緩めていない。NG設定の変更による履歴無効化、期限、検索条件ごとの分離、公式ルーターが利用できない場合の元のリンクへの復帰も維持する。新しい通信は追加しない。

合成再現：3ページを開いた後、1ページから2〜27ページを取得。27に未表示があれば斜線は2〜26、次は27。3にも未処理があれば斜線は2、4〜26、次は3。現在の1は選択表示のまま。修正前に3が処理済み集合から欠落する回帰テストの失敗を確認した。個人の検索語・動画・投稿者・画像・生診断は保存しない。

この単位では投稿者欄やNG評価器、プレビューを変更しない。プレビューは次の独立した単位で追加する。
