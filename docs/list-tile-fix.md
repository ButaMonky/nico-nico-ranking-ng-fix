# リスト／タイル表示修正（2026-09-07）

## 今回の変更

- 補充動画を常にタイル配置にしていたため、リストでは画像が最大640pxまで広がっていました。リスト時はサムネイルを320×180px相当（サイトのthumbnail.l変数があれば優先）、本文を右側に配置します。タイルでは従来の配置に戻します。
- リストのネイティブ動画はサイトの横並びを維持し、カード幅が縮まないようにします。
- `src/ui/result-layout.js` に表示切替処理を追加しました。ネイティブの結果コンテナーを基準に表示形式を判定し、DOMとclassの変化に追従します。ボタンを押した時点で先走って表示を変えません。
- 同じURLでカード全体またはカード内部が置換されても、既存のMovieRoot、タイトル・詳細UI、NG非表示状態、補充済み動画のDOMと順番を保持します。表示切替処理からNG判定、詳細取得、自動補充開始を呼びません。すでに進行中の処理は継続します。
- 別の検索語・並び順・ページへのURL変更では旧カードを復元しません。従来のSPAナビゲーション制御の担当範囲を維持します。
- 原本v14.1は変更していません。ユーザーが挙動修正を依頼したため、生成物のバイト一致制約を機能開発用に変更しました。原本ハッシュ・ソース連結結果・生成の再現性は引き続き検証します。

## 検証

従来の71件のテストに加え、`node scripts/test-result-layout.mjs` でインストール済みBraveを独立したヘッドレスプロファイルで起動します。通常使用中のBraveやTampermonkey設定には触れません。

提供されたリスト／タイルHTMLをfixturesに保存しています。外部通信を遮断し、必要なサイトCSSの配置指定を試験内で再現しています。リスト画像320×180px、本文との16px間隔、4回の全体置換、カード内部の置換、classのみの切替、タイトル・詳細UIとNG状態の保持、補充順序、処理中カードの非表示、重複防止、切替時のモデルsetup非実行、監視の収束、別URLへの復元防止を確認します。

この試験は実サイトのCSS全体や、ログイン中のBrave＋Tampermonkeyでの操作試験を代替しません。ランキングや旧検索UIも含めた全ページの実地検証は未完了です。

ブラウザー試験はこのPCの同梱PlaywrightとBraveを既定で使います。他のPCでは `NRN_PLAYWRIGHT` にPlaywrightモジュールのパス、`NRN_BROWSER` にChromium系ブラウザーの実行ファイルを指定できます。通常の71件の試験はNode.jsのみで実行できます。

## ユーザーが行うこと

1. Tampermonkeyで現在の「Nico Nico Ranking NG」のコードを開き、念のためファイルに保存しておきます。
2. `dist/nico-nico-ranking-ng-v16-list-tile-fix.user.js` を開いて全文をコピーし、現在のスクリプトのコードを全文置き換えて保存します。スクリプト名・namespaceは同じなので、既存の編集画面で置き換えれば保存済み設定を引き継げます。
3. ニコニコのページを一度再読み込みします。その後、リスト→タイル→リストと切り替えます。
4. リストの画像サイズ、補充動画が消えないこと、NG非表示が保たれること、詳細の開閉を確認します。

別スクリプトとして登録した場合は旧版を無効にして、2本同時に動かさないでください。うまく表示されなければ、初回から崩れるか・切替後だけかとスクリーンショットを伝えてください。
