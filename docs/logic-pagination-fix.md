# 論理式NG・先読み終端の見直し — 160.3

## 確認できた不具合と修正

### 論理式NG

詳細未取得の条件をfalseとしてからNOTで反転していたため、取得前にNGが成立することがありました。内部判定を「一致／不一致／未確定」に分け、AND・OR・入れ子のNOTでも未確定を維持します。例えば `NOT(指定タグがある)` はタグ取得完了後に判定します。公開evaluateNodeとmatchは、確定したtrueだけを一致として扱います。

取得失敗も、タグや投稿者が「存在しない」とはみなしません。後から取得に成功した場合はエラー状態を解除して判定します。空グループをさらにNOTで囲んでもNGは成立しません。

存在しない投稿者IDや空の数値入力を0として比較していた点も修正しました。投稿者がいないことを指定する場合は「存在しない」を使います。

ログ上では `advancedNgRulesEnabled:false` でした。個別ルールを保存しただけでは複合NG全体は有効になりません。設定の「複合NGルールを有効にする」を確認してください。ユーザーの過去の具体的な条件式は未提示のため、その事例と今回確認した不具合が同一とは断定していません。

### ページ先読み

- 最終ページ数不明のnullを0へ変換し、終端の値として採用していた箇所を修正。
- 次ページリンクが取得HTMLにないだけで `hasNextPage:false` になる点を修正。情報不足は未確定とし、明示的な終端情報と区別。
- 正常な検索JSONが空の場合は終端として停止。空ページを取得済みページ数や「次へ」で飛ばす範囲に含めず、それまで集めた候補は維持。
- 範囲外要求から前のページへ転送された場合は、その動画を新規ページとして追加せず停止。
- 検索JSONが空なのに関連動画などのDOMを拾い直す挙動を修正。DOMからの代替解析もメイン動画に限定。
- 検索結果を解析できないHTMLやログイン等への転送は、正常な終端と偽らずエラーで停止。

既知の最終ページを超える要求を送らない処理と400/404時の停止は維持しています。正確な終端超過時のユーザー操作・画面症状は未提示であり、添付ログだけでその事例全体を再現したわけではありません。
