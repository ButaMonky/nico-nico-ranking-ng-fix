# 使い方と設定

[READMEへ戻る](../README.md)

## 導入と最初の設定

[Tampermonkey](https://www.tampermonkey.net/)を用意し、[READMEのインストールリンク](../README.md#インストール)から導入します。ランキング・キーワード検索・タグ検索のページを開き直し、追加された操作欄の「設定」を開いてください。

インストール画面が開かない場合は、[配布ファイル](../dist/nico-nico-ranking-ng-v16-list-tile-fix.user.js)の全文をコピーし、Tampermonkeyの「新規スクリプト」へ貼り付けて保存できます。すでに利用している場合は新規項目を作らず、[既存項目への更新手順](distribution.md#設定を保持して更新する)に従います。原配布版とこの改変版を重複して有効にしないでください。

動作しないときはページを再読み込みし、ブラウザでユーザースクリプトの実行が許可されているか、[Tampermonkey公式の説明](https://www.tampermonkey.net/faq.php?locale=en&q=Q209)を確認してください。

| やりたいこと | 設定する場所 |
| --- | --- |
| タイトルや投稿者をNGにする | 「NG・フィルター」で種類を選んで追加 |
| 複数の条件を組み合わせる | 「条件を組み合わせるNG」で編集し、「変更を適用」 |
| 検索結果を補充する | 「自動継ぎ足し」をONにし、目標件数・追加ページ上限を指定 |
| 閲覧済みや詳細情報の表示を変える | 「表示・操作」 |
| 不具合の情報をコピーする | 「開発者・診断」→「匿名診断をコピー」 |

## NGを登録する

対象ページに追加された操作欄の「設定」→「NG・フィルター」を開きます。種類を選び、「追加」から登録します。動画ID、タイトル、タグ、ロックされたタグ、投稿者ID・名前、チャンネルIDを使えます。カードのNG操作や詳細欄の登録ボタンも利用できます。

「NGタグ」はロックの有無にかかわらず一致するタグを対象にし、「NGタグ(ロック)」はロックされているタグを対象にします。「NG動画を表示」を使うと、隠した結果を一時的に確認できます。登録した条件を削除したいときは、設定のNGリストから削除してください。

## 条件を組み合わせる

「条件を組み合わせるNG」で例からルールを作り、言葉や数を変えて試せます。

- 「すべて」：条件が全部そろった場合に一致します（AND）。
- 「どれか」：いずれかの条件に一致すれば対象です（OR）。
- 否定・例外：その条件に当てはまるものを除きます（NOT）。

編集後はルールと全体を有効にし、「変更を適用」を押します。適用するまでは下書きで、「元に戻す」「やり直す」が使えます。例外はそのルールの対象から除くだけで、ほかのNG登録を取り消す機能ではありません。

複合ルールのタイトル・投稿者名の「含む」は部分一致、タグ名は完全一致で、英字の大文字・小文字を区別しません。情報の取得失敗や未取得は、条件に一致しないと決めつけず「保留」にします。

## 検索結果の自動継ぎ足し

初期設定はOFFです。有効にすると、NGで減った検索結果を後続ページから補充します。初期値は目標36件・追加5ページまでです。候補不足や取得上限に達した場合は、目標件数に届かなくても止まります。

取得方式、広告の扱い、ページ番号の表示を設定できます。検索条件・並び順を取得方式で再現できない場合は、従来の取得方式へ戻ります。追加ページの情報取得には通信が発生します。

## 追加カードのプレビューと公式操作

「追加カードのホバープレビュー」は試験機能で、初期設定はOFFです。ONにすると、カードにマウスを置いてから読み込み、最大30秒再生します。離脱・画面外・タブ非表示などで停止します。コメントの表示や音量も扱いますが、全描画・全コマンドとの互換はありません。

公式カードと追加カードの消音状態を文書内で合わせます。ただし、公式のボタンがまだ現れていない段階の内部状態を直接読み取ることはできません。未知・未対応のコメントNG設定では、映像のみ表示します。

「あとで見る」と公式の投稿者非表示・解除は、クリックによりニコニコのアカウントへ反映されます。スクリプトのNGリストとは別の設定です。利用にはログインなど公式側の条件が必要です。

## 表示・操作

「表示・操作」では、閲覧済み動画の表示、独自UIの配色、動画詳細・説明の開閉、ページ内移動への追従を設定します。通常の設定は変更時に保存されます。複合NGの下書きだけは「変更を適用」が必要です。

詳細情報のセッションキャッシュは、取得済みのタグや投稿者情報を同じタブで再利用する機能です。設定バックアップとは別で、有効期限内でも元情報が変化すると古い情報が残る場合があります。NG判定は現在の設定でやり直します。

## データ管理とバックアップ

CSVで入出力できるのは、動画ID・タイトル・タグ・ユーザーID・ユーザー名・チャンネルID・閲覧済みの7種類です。インポートは対応するリストへの追加です。ロックタグ、複合ルール、補充・表示設定はCSVに入りません。

更新・移行前はTampermonkey側で保存データを含むバックアップを取ってください。バックアップにはNGや閲覧情報が入るため、自分の端末内で保管します。[詳しい移行手順](distribution.md#設定を保持して更新する)

## 不具合の情報を確認する

「開発者・診断」→「匿名診断をコピー」を使います。版や処理件数を共有するための機能です。コピー内容を確認してから報告に添付してください。コンソール全体のログやHARは不要です。

この改変版の[不具合報告フォーム](https://github.com/ButaMonky/nico-nico-ranking-ng/issues/new?template=bug_report.yml)へ、次の情報を分かる範囲で記載してください。原配布元への問い合わせは不要です。対応時期や継続的な更新を約束するものではありません。

- スクリプト、ブラウザ、Tampermonkeyの版
- ランキング／検索などのページの種類と、リスト／タイルの違い
- 問題が起きる操作、期待した結果、実際の結果
- 必要に応じて、内容を確認した匿名診断の出力

HAR・保存ページ・生ログ・閲覧画像・設定バックアップ・認証情報は添付しないでください。個人名・メール、動画や投稿者のID、実際の検索語、閲覧URL、端末の個人パスも不要です。
