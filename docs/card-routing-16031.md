# 160.31: 自動補充カードのクリック範囲

## 原因と変更

画像・タイトルにはリンクがあったため、外部プレイヤーのZenボタンは表示できた。一方、追加カードの親要素には公式カードの `data-group="true"` / `data-anchor-href` がなく、投稿日・再生数をクリックしても動画URLを解決できなかった。

追加カードにこの情報を付与し、投稿者リンクには公式の `data-group-ignore="true"` を付与する。特定のスクリプト名・クラスを判定する分岐や、新しいクリックハンドラーは追加しない。画像・タイトル・投稿者のhrefと既存の保存形式は維持する。

ZenzaWatch側は、カードの動画リンク・投稿日とその間の余白だけを起動対象とする。追加された詳細トグル、操作ボタン、投稿者欄は対象外。双方の安定版（NG Fix 160.31、ZenzaWatch 2.7.395-task1021）を更新して確認する。

## 検証

- `node scripts/test-injected-card-routing.mjs`：修正前は投稿日から動画URLを解決できず失敗、修正後は成功。
- `ZENZA_REPO` にローカルのZenzaリポジトリを指定すると、その `dist/ZenzaWatch-dev.user.js` の実際のHoverMenuで追加カードを判定。画像・タイトル・投稿日・再生数を許可し、投稿者・追加span・buttonを除外する。リスト／タイル両方で確認。
- `node scripts/test.mjs`：389件成功。
- `node scripts/test-result-layout.mjs`：既存の表示切替・ノード保持・監視終了を確認。
- ブラウザ試験は `NRN_PLAYWRIGHT` / `NRN_BROWSER` を端末に合わせて指定する。合成データを使うオフライン試験であり、ログイン済み実サイトの確認とは区別する。

## 利用者の確認

自動補充で追加された動画の画像・タイトル・投稿日・再生数とその間の余白をクリックする。Zenzaの直接クリック起動がONなら開き、▼・投稿者・メニューボタンでは開かないことを確認する。タイル／リスト表示を切り替え、フォロー新着でもページ遷移と二重再生が起きないことを確認する。
