# 160.24 製品ブランチの送信前確認

2026-09-20。利用者のGitHub送信指示に基づく作業。既存リポジトリの非公開設定は維持する。

## 送信範囲

製品の160.24と開発・検証文書を対象とする。独立した研究ブランチ、ローカル専用引継ぎ、HAR、保存ページ、診断の生データ、画面画像は含めない。既存の研究ブランチの内容や履歴は変更しない。

## 履歴の整理

- 元の作業コピーを保持し、製品の52コミットを別の送信用リポジトリに再構築した。
- コミットの作成者・記録者はGitHubの公開ハンドルとnoreplyアドレスを使用する。個人メールや端末名を送信しない。
- 過去の端末固有パス、文書の実動画ID・検索語、広告fixtureの題名・画像URL、試験に使っていた実投稿者IDを架空値へ置換した。
- 古い一覧HTMLの各版も匿名化済みの合成fixtureに置換し、署名付き画像URLや閲覧内容が過去の版から取り出せないようにした。
- 製品ソース、配布スクリプト、固定した原本とそのハッシュは変更していない。fixture変更後の回帰試験を行う。
- 以前のコミットIDは変わる。過去文書中の短縮IDは当時のローカル記録であり、今後はタスクIDと版番号を主な参照とする。

現在ツリーの検査に加え、送信先端から到達する全コミット・全blob版を検査する。新しい `scripts/check-privacy-history.mjs` は端末パス・認証値・署名付きURL・生資料・コミットメールを検査し、値自体を出力しない。文書とfixtureの確認も別に行った。

## 送信時の条件

履歴整理後の新しいクローンで、ビルド、183件の単体試験、構文、現在ツリーと全履歴のプライバシー検査、必要な模擬ブラウザ試験を再実行する。送信は製品の `master` だけに限定し、全ブランチ・タグをまとめて送信しない。既存の先端が確認時点から変わっていれば上書きを中止する。

履歴書き換えは既に承認された個人情報除去に必要な範囲で行う。今回変更しない研究ブランチやGitHub側の旧参照・キャッシュまで削除済みとは扱わず、リポジトリ全体の完全消去とは区別する。実サイトでの全動作検証、UI・設定画面の残作業、連続再生の詳細実装は完了扱いにしない。
