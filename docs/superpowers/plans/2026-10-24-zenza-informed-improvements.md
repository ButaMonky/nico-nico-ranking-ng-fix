# ZenzaWatch知見を活用した改善計画

**Goal:** 本家と既存NG機能の契約を保ち、キャッシュ、通信、SPA、プレビュー、NG・補充の確認可能な不具合を修正して配布する。
**Architecture:** 現行JavaScript構成を維持し、取得・保存・復元とライフサイクルの境界を修正する。ZenzaWatchの実DBや認証情報は読み取らず、新しいAPIを推測で追加しない。
**Tech Stack:** JavaScript userscript、Node標準テスト、オフラインPlaywright。
**Spec:** 利用者の2026-10-24依頼とAGENTS.md。確認なしの実装・push、並列エージェント利用を明示承認済み。

## 制約と根拠

- 基点は新製品リポジトリのmaster `dd50b6f`。旧コピーの未コミット変更を混ぜない。
- 調査知見: 参照時刻は取得時刻ではない。投稿者type/id/nameとタグlockは別の情報。未知を空や非該当へ変換しない。
- 固定版ZenzaWatchのコード調査と現行実サイトの動作確認は区別する。
- 本家UI・既存設定形式を維持。生資料・個人情報を成果物へ追加しない。
- 正常系の基点: 単体369件成功。独立した領域を分担し、生成物のビルド・統合・送信は主担当だけが実行する。
