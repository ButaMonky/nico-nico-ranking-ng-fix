# 160.17 投稿者欄の表示統一

## 変更

通常表示の補完欄を、提供された公式HTMLと同じ「リンク内に画像と名前の段落」の構造にした。画像・横並び・余白・色・文字サイズ・太字・一行省略・狭いコンテナーでのサイズ変更には、公式欄と同じ表示クラスを使う。独自の固定サイズと上余白を除き、古い投稿者リンク用の `display:inline !important` と色指定が補完欄を上書きしないようにした。詳細欄の投稿者表示も同じ部品を使う。

計測・解析用の公式属性は生成せず、公式DOMを投稿者情報の根拠として扱う既存の区別を維持する。元の投稿者欄、型・IDの照合、投稿者クリック、▼の開閉時の二重表示防止、キャッシュ、SPA対応は維持する。標準画像は提供HTMLの公式プロフィール画像URLに統一した。過去の投稿者の本人画像・最新画像であることを保証する変更ではない。

詳細欄のダーク設定が通常欄の文字色まで変えないようにした。詳細欄自体は読みやすさのため既存のダーク配色を保つ。現在の表示クラスを持たない旧形式の検索画面では、その画面専用CSSで横並びと24pxの画像サイズを維持する。

プレビューは別タスクの解析に任せ、この版では実装・追加調査をしない。新しいAPI通信も追加しない。
