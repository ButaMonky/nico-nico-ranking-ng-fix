# 160.5 — 詳細ボタンと開発者ログ

広告ポイント表示に詳細開閉ボタンが覆われる報告に対応。現行UIのボタンをz-index 20で前面に置き、操作範囲を22×20pxから26×24pxへ拡張した。固定位置の計算と開閉処理は維持する。

スクリプトのクロージャ内にconsoleのラッパーを設け、設定同期前と開発者モードOFFでは通常ログ、診断警告、表、グループ出力を抑制する。設定変更は次の出力から反映する。console.errorは保持する。ページや別スクリプトのconsoleを変更しない。設定が同期する前の診断ログは再出力しない。

検証: 構文確認成功、自動テスト96件成功。Chromeの独立したヘッドレス環境で、保存済みリスト／タイルHTMLを使う既存の切替試験に合格。広告表示を模した重なりを追加し、固定前後のボタン中央・四隅のうち2点でelementFromPointがボタンを返すこと、操作範囲26×24pxを確認。OFF/ON/OFF切替、初期化前の抑制、エラー保持、外側consoleの保持も検証した。

ユーザーのChrome/Tampermonkeyにはまだ導入していない。実サイトのCSS・全画面幅での確認は未実施。ERR_BLOCKED_BY_CLIENTやZenzaWatch由来のログは本修正の対象外。
