# 160.8 条件を組み合わせるNG

## 使い方

1. NG設定の「条件を組み合わせるNG」を開き、例を選んで「この例から作る」を押す。
2. 「何を」「どう比べる」「値」を編集する。「すべて」は全部がそろった動画、「どれか1つ以上」は1つでも合う動画を対象にする。
3. 「動画で判定を試す」を開く。手入力、または「このページの動画を読み込む」で取得済みの動画から選ぶ。選択中のルールの一致・不一致・保留と、各条件の実際の値を確認する。
4. 「このルールを使う」と全体の有効化を確認し、「変更を適用」を押す。

新規・複製ルールは休止で追加される。条件編集と全体の有効化は適用するまで現在のNG設定を変えない。この下書き方式は複合NGだけが対象で、他の設定項目は従来どおり即時保存。

## 変更内容

- 「論理積」「論理和」中心の表記を日本語の条件文に置換。条件間に「かつ／または」、まとまりに説明、ルール全体に読み返し用の文章を表示する。
- 白紙、タイトル＋タグ、複数の言葉、好きなタグを除外、同一投稿者のページ内投稿数の5つの作成例。
- 「例外を追加」で既存式と否定したグループをANDで結合。例外はこのルールだけに作用し、別のNGを解除しない。
- ルール一覧・名前検索、休止、複製、削除。条件とグループの複製・上下移動。マウスドラッグを必須にしない。
- 下書きの元に戻す／やり直す（直近30操作）。削除も取り消せる。保存済みへの復帰、閉じる前の未適用確認、別画面の変更との競合検出。
- 空欄を0へ変換しない。IDは正の整数、個数は非負整数、ページ内件数は1以上、タグ数は0～11。空グループ・深すぎる入れ子は適用を止めて説明する。休止中のルールも入力確認の対象。
- 通常のNG判定と同じ `evaluateState` でプレビューする。広告情報など未取得の条件は保留し、NOTでも一致に反転しない。プレビューは選択中のルールだけを、休止・全体OFFを無視して試す。他ルールや単独NGも含めた最終表示の予測ではない。
- 実動画プレビューは現在のモデルから最大100件。追加通信は発生しない。ページ内投稿数や広告照合が未確定なら、そのまま保留になる。
- 「IDがない＝退会済み」と誤解させる説明を修正。退会済み投稿者の取得調査は `BACKLOG.md` へ保留として記録。

## 互換性と限界

保存形式・条件項目・既存のルール評価は維持する。旧形式の移行も既存のparseを利用する。保存済みルールを読み込むだけでは設定を書き換えない。編集エンジンは独立ファイル `src/ui/rule-editor.js` とし、設定画面を開いたときだけ生成する。

適用後は情報が揃った動画から再判定される。ページ内投稿数や広告照合など取得方式に関わる設定を追加した場合、十分な情報を取得するには次の検索移動が必要な場合がある。プレビューの手入力タグは編集時にロック指定を解除する。ロックタグ欄で追加したタグはタグ欄にも反映する。

今回、Tampermonkeyへのインストール・実サイト操作・GitHubへの送信は行っていない。生成物のバージョンは160.8。
