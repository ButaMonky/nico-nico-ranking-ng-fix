# 160.32: 裏タブ継続・NG記憶・ランキング・SPA起動（BRUSH-059〜062）

作成: 2026-11-15 claude（Lane C）。対象ブランチ `claude/brush-059-062`。master 未統合。実サイト未確認。

## BRUSH-059 裏のタブでNGが止まる

- 原因: 結果DOM変更後の解析（list-page の MutationObserver）、カード装飾、AutoFill の描画待ち（waitForPaint）が `requestAnimationFrame` 依存。非表示タブでは rAF が実行されない。
- 対策: `nrnRequestFrame`（src/core/events.js）。表示中は rAF、非表示中は MessageChannel タスク。予約後に非表示になった場合は 200ms のタイマーで補う。戻り値は取消関数。
- 残る制約: AutoFill の初期カード待ち（100ms ポーリング）はタイマーなので、非表示タブでは1秒間隔に間引かれる（5分以上非表示なら更に間引かれる場合あり）。停止はしない。
- 試験: tests/background-frame.test.mjs（4件）。

## BRUSH-060 NG記憶（ngVerdictCache）

- 保存: GM値 `ngVerdictCache` = `{"v":2,"b":{"t:FOO":"sm1 sm2",...}}`。IDのみ、NG設定ごとのグループ。手動の ngMovies とは別。
- グループ: `u:`投稿者/チャンネルID、`n:`NG投稿者名、`t:`NGタグ、`l:`NGロックタグ、`k:`ロックタグ数しきい値、`r:`複合NGルール（ルールID＋条件式のハッシュ。1件の編集はそのルールのみ無効）。動画ID・タイトルNGは即判定できるため記録しない。
- 削除: 設定変更時と起動時（Config同期後）に無効グループを丸ごと削除。通常判定でNGでない動画は1件削除。日時では削除しない。合計20万件超過時は最大グループの古い順に削除。複数タブの保存はグループ単位でマージ。
- 早期非表示: document-start で同期 `GM_getValue` が使える場合のみ。MutationObserver で `[data-decoration-video-id]` に `data-nrn-prehide` を付け、描画前に隠す。通常判定が確定したら外し、以後は従来の `nrn-hide` に任せる。未確定でも20秒で外す。「NG動画を表示」ON、記憶OFF、getthumbinfo OFF では使わない。早期経路は削除を行わない（設定が未確定のため）。
- AutoFill: CandidateFilter が有効グループの候補を通信前に除外（理由 `verdictCache`）。既存の「詳細で置き換わり得る情報で事前判定しない」方針に対する、利用者が選んだ例外。
- 試験: tests/verdict-cache.test.mjs（9件、jsdom があれば早期非表示も実行）。

## BRUSH-063 目標件数で本来のカードを隠さない／ランキングは対象外

- 原因: `rebalanceOverflow` が、表示中のカード（ページ本来のカードを含む）のうち目標件数を超えた分に `nrn-autofill-overflow` を付けて隠していた。ランキングは100件あるため、36〜39件しか見えなかった。
- 対策: 本来のカードは目標件数では隠さない。目標までの残り枠を超えた追加カードだけを予備として隠す。ランキング（/ranking/）では自動継ぎ足しも目標件数も適用せず、状態表示は「ランキングでは補充なし」「N件表示」。
- 試験: test-ranking-parse（目標1件・自動継ぎ足しONでも隠さない・取得しない）、test-autofill-card-budget を新しい規則に更新（本来の36件＋広告5件＝41件すべて表示、補充ケースは目標36件まで）。
