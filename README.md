# ニコニコランキングNG

ニコニコ動画のランキングや検索結果に、見たくない動画を非表示にする **NG機能** を追加するユーザースクリプトです。ブラウザ拡張のTampermonkeyから利用します。

[kengo321氏のNico Nico Ranking NG](https://greasyfork.org/ja/scripts/880-nico-nico-ranking-ng)をもとに、複数条件のNG、検索結果の自動補充、表示や操作の修正などを加えた**非公式の改変版**です。ニコニコ公式の製品ではありません。

**現在の版：160.25** · [変更履歴](CHANGELOG.md) · [使い方と設定](docs/usage.md) · [既知の制限](#既知の制限)

## できること

- **動画を条件で非表示にする** — 動画ID、タイトル、タグ、投稿者ID・名前、チャンネルIDなどをNGに登録できます。
- **条件を組み合わせる** — 「タイトルにこの言葉が含まれ、特定のタグが付いている」など、複数条件や例外を使えます。
- **検索結果を補充する** — NGで減った分を後続ページから追加し、指定した件数に近づけます。必要なときだけONにできます。
- **一覧を使いやすくする** — 閲覧済み動画の表示切替、タグ・投稿者情報の表示、リスト／タイル表示、ページ内の検索切替に対応しています。

自動追加カードの**ホバープレビューは試験機能で、初期設定はOFF**です。通常のNG機能だけでも使えます。

## インストール

1. [Tampermonkey](https://www.tampermonkey.net/)を、利用しているブラウザへインストールします。
2. **[ニコニコランキングNGをインストール](https://raw.githubusercontent.com/ButaMonky/nico-nico-ranking-ng/master/dist/nico-nico-ranking-ng-v16-list-tile-fix.user.js)** を開き、Tampermonkeyの確認画面でインストールします。
3. ニコニコ動画のランキング、キーワード検索、タグ検索のページを開き直します。追加された操作欄の「設定」からNGを登録できます。

スクリプトが動かない場合は、ブラウザ側でTampermonkeyのユーザースクリプト実行が許可されているか、[公式の説明](https://www.tampermonkey.net/faq.php?locale=en&q=Q209)を確認してください。

インストール画面が開かない場合は、[配布ファイル](dist/nico-nico-ranking-ng-v16-list-tile-fix.user.js)の全文をコピーし、Tampermonkeyの「新規スクリプト」へ貼り付けて保存できます。

リポジトリが非公開の間は、GitHubへの閲覧権限があるアカウントでファイルを取得する必要があります。

> すでに利用している方は、下の「更新方法」を確認してください。原配布版とこの改変版を重複して有効にしないでください。

## 更新方法

**現在、この改変版は手動更新です。**

新しい版が出たら[変更履歴](CHANGELOG.md)を確認し、上のインストールリンクから更新してください。

原配布元から別系統のスクリプトが自動的に上書きされないよう、この改変版では自動更新を停止しています。

更新前には、Tampermonkeyのユーティリティからバックアップを作成してください。**スクリプトの保存データも含めて**保存することをおすすめします。

新版を開いたときは、既存の「Nico Nico Ranking NG」の更新になっていることを確認してください。別のスクリプトとして追加されそうな場合は、既存スクリプトの編集画面へ新版の全文を貼り付けて保存してください。

**旧版を先に削除しないでください。**

### 160.24以前から移行する場合

一度、この改変版を手動でインストールしてください。

以前の版では更新先が原配布元を指している場合があるため、Tampermonkeyの「更新を確認」だけではこの改変版へ移行できません。

詳しい移行手順とバックアップの範囲は [配布・更新の仕様](docs/distribution.md) を参照してください。

設定画面のCSV出力は一部のNGリスト用です。**ロックタグ・複合NG・表示や補充の設定を含まないため、完全なバックアップにはなりません。**

## 最初の設定

ページに追加された操作欄の「設定」を開きます。

| やりたいこと | 設定する場所 |
| --- | --- |
| タイトルや投稿者をNGにする | 「NG・フィルター」でNGの種類を選んで追加 |
| 複数の条件を組み合わせる | 「NG・フィルター」→「条件を組み合わせるNG」。編集後に「変更を適用」 |
| 検索結果を補充する | 「自動継ぎ足し」をONにし、目標件数と追加ページ上限を設定 |
| 閲覧済み動画や詳細情報の表示を変える | 「表示・操作」 |
| 不具合の情報をコピーする | 「開発者・診断」→「匿名診断をコピー」 |

自動継ぎ足しとホバープレビューは初期設定でOFFです。

まず通常のNG機能だけを設定し、必要に応じて追加機能を有効にできます。

詳しくは [設定項目の説明](docs/usage.md) を参照してください。

## 既知の制限

| 状態 | 内容 |
| --- | --- |
| 実装済み | 基本NG、複合NG、自動補充、リスト／タイル表示、ページ内の検索切替への対応 |
| 実装済み・実サイトの確認を継続 | 追加カードの「あとで見る」、共有、広告画面、公式の投稿者非表示・解除、ページ番号の整理 |
| 試験機能 | 追加カードのホバープレビュー。全コメントコマンド・コメントアートには非対応。未対応のコメントNG設定では映像のみ |
| 一部実装 | 「ここから連続再生」。取得ページに公式の再生リスト情報がある場合のみ表示。ページをまたいだ再生やNGとの詳細な整合は引き続き開発中 |

「実装済み」は、すべての環境で動作確認済みという意味ではありません。

ニコニコ側の変更や通信状況によって動作が変わることがあります。個別のランキング形式、ショート動画、モバイルなど、未確認のページを対応済みとはしていません。

投稿者情報の補完は、同じ動画・投稿者と確認できた情報を利用します。すべての投稿者名や現在名を復元できるわけではありません。

自動補充についても、候補数、NG条件、取得上限によっては目標件数まで届かない場合があります。

本プロジェクトでは、可能な限り**ニコニコ本来の見た目・操作・状態管理に合わせること**を優先しています。

詳しくは [検証結果と残る制限](docs/distribution-16025.md) と [作業一覧](docs/TASKS.md) を参照してください。

## 不具合・質問

[Issues](https://github.com/ButaMonky/nico-nico-ranking-ng/issues)へどうぞ。

不具合は[報告フォーム](https://github.com/ButaMonky/nico-nico-ranking-ng/issues/new?template=bug_report.yml)から、次の情報を分かる範囲で記載してください。

- スクリプト、ブラウザ、Tampermonkeyのバージョン
- ランキング／検索など、問題が発生したページの種類
- リスト／タイル表示の違い
- 問題が起きる操作
- 期待した結果
- 実際の結果
- 必要に応じて「匿名診断をコピー」の出力

**HAR、保存ページ、生ログ、閲覧画像、設定バックアップ、認証情報は添付しないでください。**

個人名・メールアドレス、実際の検索語、閲覧URL、端末内の個人用パスなども不要です。

匿名診断についても、貼り付ける前に内容を確認してください。

この改変版についての報告は、このリポジトリへお願いします。原配布元へ問い合わせる必要はありません。
